# What Dragoon.app may hold besides its source snapshot. tools/check_bundle.py reads this.
# The format is described at the top of tools/bundle_manifest.py. A path that no line allows
# is a finding, so a new file in the app starts as a line here, reviewed on its own.

# The snapshot from export_source.py. check_bundle.py compares it with a fresh export instead
# of listing it here.
source Contents/Resources/source

# The download is 60 MB at most (the player target in the launcher plan).
budget dmg 60000000
# PLACEHOLDER until the launcher and Sparkle are built. At Dragoon db8d24b the engine kit was
# 5.4 MB and the source snapshot 6.1 MB. Sparkle and the launcher are guessed at 6 MB, what's
# left of a 12 MB estimate for them and the snapshot together. That's 17.5 MB, plus a
# quarter. Keep it under 101 MB so the generated C alone breaks it.
budget app 22000000

# The launcher. It builds the game with the player's own Command Line Tools and the kit below,
# so the app holds no CMake, Ninja or SDL source.
macho Contents/MacOS/Dragoon
file Contents/Info.plist
# Made by codesign when L16 signs the app.
file Contents/_CodeSignature/CodeResources

dir Contents/Resources/licenses/

# The engine kit tools/engine_kit.py makes, which launcher_build.py builds the game with
# (--kit). It sits in Resources beside the snapshot, since both are data the recipe reads and
# neither runs by itself. codesign seals its files as resources and signs none of them.
# check_bundle.py reads both objects with nm, and lets the engine alone hold the disc ID, which
# it carries as a public constant.
engine Contents/Resources/kit/engine.o
object Contents/Resources/kit/libSDL3.a
file Contents/Resources/kit/kit.mk
file Contents/Resources/kit/Makefile
file Contents/Resources/kit/include/recomp.h
file Contents/Resources/kit/include/compat.h
file Contents/Resources/kit/licenses/gcn-recomp.txt
file Contents/Resources/kit/licenses/SDL3.txt
file Contents/Resources/kit/licenses/hidapi.txt
