# rom/

Put your own Kirby Air Ride disc image here (USA, disc ID `GKYE01`) as `rom/game.iso` or
a `.ciso`. A `.gcm` dump is the same format as an `.iso`, so rename it or link it as
`rom/game.iso`.

Everything in this folder except this README is ignored by git. Never commit or share disc
images. `docs/BUILDING.md` covers dumping your disc.
