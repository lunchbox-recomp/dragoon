# rom/

Put your own Kirby Air Ride disc image here (USA, disc ID `GKYE01`) as an `.iso` or `.ciso`,
such as `rom/game.iso`. Keep one image here, since the configure takes the first it finds. A
`.gcm` dump is the same format as an `.iso`, so rename it or link it as `rom/game.iso`, while
an `.rvz` or `.gcz` needs converting first.

Everything in this folder except this README is ignored by git. Never commit or share disc
images.
